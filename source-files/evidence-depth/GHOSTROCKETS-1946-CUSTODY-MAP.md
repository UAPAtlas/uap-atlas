# Ghost Rockets — Swedish Custody Map

- Official archive creator: **Försvarsstaben**
- Responsible unit: **Flyg- och luftförsvarsavdelningen**
- Official series context: **Rymdprojektilkommittén**
- Repository: **Riksarkivet i Täby, Krigsarkivet**
- Strict scan mappings: **12**

## What is now mapped

Twelve public scans contain the same internal order reference — `Fst/L 12/6 1946 nr 7:49` — and route reports to the Försvarsstaben air/air-defence unit identified by Riksarkivet as the responsible authority for the Ghost Rocket investigation.

`000682.pdf` and `000955.pdf` were visually checked against their scans. The remaining ten passed the strict OCR reference rule and have downloaded, hashed original PDFs.

## Boundary

This establishes archive creator, responsible unit, investigation series context, and internal file reference. It does **not** recover the exact Riksarkivet volume/item shelfmark for each scan, and it does not prove the private uploader preserved complete archival order.
